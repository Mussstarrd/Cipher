# ONE OF ONE pack generators

`node tools/one-packs/gen-genres.js` rewrites `src/one/genres.js` from the pack data files here.
`gen-one.js` builds the single ONE OF ONE button: the eleven hit archetypes in `genre-hits.js`
fused with `src/one/personality.js` (signature harmonica/erhu family, beat-3 slur cadence,
syncopation and twitch tags, anti-transition phrases, lyric layouts, the weird v6-wild lane).
Every other pack is generated with `show: false` and stays reachable by id for tests.
