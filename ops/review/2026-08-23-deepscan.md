## 2 · What broke, root-caused

- **Adults check-in content vanished (FIXED).** wake() returns {family, adults};

  daily log and nowhere else — the app's room filter was ready for adults
  reports that were never stored. Every adults-only briefing, including the
  paper portfolio, was invisible in the app. Fixed: stored as a second report
  with room:"adults", server-filtered exactly like adults messages, labelled in
  the UI. This touches room *plumbing* but not room *policy* — the existing
  filter enforces it; judged in-bounds. Flagging it here for Jeffery anyway.
- **Restart-per-status-commit (FIXED).** The updater restarted the service for
  every commit, including the heartbeat's own status commits — a pointless
  restart every two hours (visible: "active since 06:39" after a status-only
  pull). Now restarts only when server/ changed.
- **Silent zero-target reminders (FIXED).** A "for: Jeffery" reminder matching
  no name-tagged subscription fired to nobody. Both current subs predate
  tagging, so the first targeted reminder would have failed silently. Now falls
  back to all subs — shared list, leaks nothing, fails loud instead of quiet.
