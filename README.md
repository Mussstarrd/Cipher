# Cipher — Hearth

A collective family assistant that reviews its own day every night and is
therefore better tomorrow than it was today.

Most family organizers are a shared calendar with reminders: exactly as smart on
day 400 as on day one. Hearth's premise is the opposite — a nightly self-review
that writes down what it learned, so the knowledge of how this household
actually works accumulates somewhere other than one person's head.

## Layout

| Path | What it is |
| --- | --- |
| `CLAUDE.md` | Operating brief. Loaded automatically into every session. |
| `memory/` | The five memory layers. This is the product. |
| `.claude/skills/` | The three routines: morning brief, evening review, household Q&A. |
