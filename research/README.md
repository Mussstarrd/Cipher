# The trading lab — two agents learning a strategy on paper

Granted by Jeffery 2026-08-23. The design session can read the live web; Hearth
lives with the family and holds the paper book. Each teaches the other:

- **Design session → Hearth**: `research/notes/YYYY-MM-DD.md`, weekday mornings
  before the open. World context (geopolitics, semiconductors), per-ticker
  thesis updates, and explicit "what would change my mind" lines. Pushed like
  any commit; the droplet pulls it within 15 minutes.
- **Hearth → design session**: its trades and stated reasoning in
  `memory/portfolio.md`, its digested lessons in `memory/topics/investing.md`
  (written by the nightly review). The next morning's note begins by grading
  yesterday's reasoning against what actually happened.
- **Strategy** lives in `research/strategy.md` — the rules both agents obey and
  the hypotheses currently being tested. It changes only with a written reason.

Bounds, restated because they do not bend: pretend money only, real trades
never, adults-room only, and Jeffery can say stop at any time.
