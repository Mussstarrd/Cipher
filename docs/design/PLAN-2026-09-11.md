# The plan, as of 2026-09-11

**Status:** live plan. Supersedes the schedule half of `ROADMAP-graphical-beta.md`.
**Answers:** the owner's question, *"OK so what is the plan now"*

## Where we actually are

The machine underneath is further along than the picture, and by a wide margin.

| Layer | State |
|---|---|
| Simulation | A thousand agents at 165 fps. Flow fields, breaches, turret line of sight, mobs that do not all run the same errand. Deterministic, state-hash guarded. |
| Match loop | Scan cycle, untimed opening, player-called last wave, pack-up window, truck extraction. |
| Progression | Gear with one comparable power budget, loot, wave-clear upgrade picks, permanent levels and a skill tree. All of it reaches the hero. |
| Interface | Build wheel, kit panel, skill screen, truck screen, upgrade offer. |
| Rendering | URP, comic-book cel shader with ink outlines and halftone, overcast winter lighting, 159 tests, a self-screenshotting smoke test. |
| **Art** | **Real people, walking.** Free CC0 models, hero and crowd, dressed winter level, colour grade. Cost: nothing. |

Every row now has something real in it. What is missing is not capability, it is CONTENT: one
hard-coded arena rather than twelve authored missions.

## The blocker is gone

**Nothing is waiting on the owner.** The purchase this plan was built around turned out to be
unnecessary: Quaternius ships CC0 characters, vegetation, streets and vehicles, verified against their
own licence file, and the whole art pipeline now runs on them. See ADR-007 decision 2, corrected.

What that bought, on the same day: a hero with a body, a crowd of real people walking on the
simulation's own agent positions, a dressed winter level of 262 props, and a colour grade. The three
week estimate that started at a purchase now starts at nothing.

## What I do next, in order, without needing anything

### 0. Done since this plan was written

Hero body, walking crowd on live agent positions, environment dressing, colour grade, smoothed-normal
outlines, and two real bugs found by review and fixed with regression tests. All pushed.

### 1. Missions become data, not code — DONE 2026-09-11

Shipped. `Assets/Resources/Scenarios/act1-01-the-gate.json` is a real mission and the game opens on it: map
size, walls, gates, hero spawn, vault, economy, director seed, wave table and objectives all come from the
file. Objectives decide the verdict, so a mission can be won by a clock rather than a kill count, which is
what seven of Act One's twelve missions need. The owner can change a wave table without a rebuild.

The remaining gap is the three objective types that need the Structure/Process/Crew actor system. They are
refused by name at load rather than loading as objectives that can never complete.

### 2. The Gate, as an actual layout — DONE 2026-09-11

Three staggered fence lines with the gaps low, high, low, so the route is a serpentine rather than a
corridor; brick pillars with concrete caps, a guardhouse, jersey barriers and a raised boom barrier at each
gate; treeline and abandoned vehicles either side; a road down the lane that stops where the walls do.

All of it authored in the mission file, so the next position is a text file rather than a code change.

### 3. The interlude between positions — DONE 2026-09-11

Leaving a position loads the next one, and what is left of the cycle becomes materials at the new line
alongside whatever came off the truck. The after-action screen is where the trade is finally legible: waves
held, what made the truck, what stayed bolted down, time left and what it bought.

The owner's "stealth up and trap up and fortify and rest" is expressed as buying power rather than as a
separate phase, because the opening setup at a new position is already untimed — time spent not fighting has
to arrive as something you built with it.

There are two positions now: The Gate falls back to The Clubhouse.

### 4. The things I owe from earlier

- Patrol drone waypoints. The simulation has been finished and tested for days; the game has no way to draw
  a route, so the feature is invisible.
- Cover props, so the open ground has texture as *cover* before it has texture as art.
- ~~`docs/02-FLAGSHIP-PITCH.md` is still the old kingpin pitch.~~ Rewritten 2026-09-11 against all four

### 5. The crowd at a thousand

The skinned-character path tops out in the low hundreds, which is why only the nearest agents get a body
today. `CrowdBaker` already writes the animation textures ADR-007 calls for; what is missing is the shader
that reads them. That is the work that makes all thousand real, and it is no longer urgent, because the part
of the crowd a player can read already looks like people.

### 6. What Act One still needs

Missions 3 to 12 are designed in `campaign-act1.md` and not authored. That is now a content job rather than
an engineering one — see `docs/design/authoring-a-mission.md` — with three exceptions that need code first:
the Structure/Process/Crew actors the clock missions are built on, the safe zone, and the lab release.

## Revised estimate

The three-week figure in the old plan started at a purchase that never needed to happen, and roughly half of
what it covered is already done. What remains for a playable graphical beta of Mission 1 is the level itself:
scenario data, the gate laid out as a real place, and a dressing pass on it.

**About a week**, and nothing in it waits on the owner.

## What I am deliberately not doing

- **Android.** The variant explosion that blocked it is fixed, but validating on a device is a day of work
  that buys nothing until there is something worth looking at.
- **Couch co-op.** Phase 4. The loadout seam makes it cheap later; doing it now would double the surface of
  every system still in flux.
- **DOTS.** Rejected in ADR-007 with reasons. It costs the deterministic simulation, and that is not a trade
  worth making for batching we do not yet need.
- **More concept art.** We have enough to direct from. More pictures are not progress.
