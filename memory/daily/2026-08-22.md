## What this actually proves

The scheduler is not the hard part; it worked first time. The hard part is that a
scheduled run is only as useful as the credentials and write access it inherits,
and it inherits far less than the session that created it. A heartbeat that can
think but cannot read the mail or commit what it learned is a demo, not a system.
